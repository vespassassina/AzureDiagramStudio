## Frozen Production Contracts

- `src/model.ts`: keep proven entity geometry (`x/y`, positive `width/height`, IDs, kind, text, icon, color, optional parent ID/status). Add canonical document metadata: `schemaVersion: 1`, stable `id`, `subtitle`, `synthetic`, `legendVisible`, custom `legend` entries and `revision`. `parentId` accepts string/null/omitted at type boundary; normalization uses null for root. Entity `layer` is foreground/background (default foreground). Connection adds optional source/target side auto/top/right/bottom/left, `routeRevision`, `labelPosition` and points. Saved routes may only be used at a matching document revision.
- Preserve pure absolutePosition, historyCommit/Undo/Redo and boundary-removal behavior, but use canonical V1 fixtures. Provide `createDocument(id, title?)` for a blank canonical document and `sampleDiagram()` for the explicitly synthetic sample. Keep 100 history transactions. History is session-only.
- Shared text geometry: export `wrapText` and `measureEntity(entity)` or an equivalently named frozen helper with deterministic measurements used by commands and renderer. Long labels/notes grow tiles; their complete text cannot be clipped. Agents may not invent separate text sizing rules.
- `src/contracts.ts`: freeze `DocumentCommand`, result types, clipboard and EditorProps before parallel dispatch. Result type: `{ok:true,value:T,warnings?:string[]}` / `{ok:false,errors:{path:string,message:string}[]}`. Mutation commands return a new Diagram or throw a meaningful DomainError; no randomness or side effects inside them.
- DocumentCommand: add entity; update entity patch; remove entity/connection IDs; move parent-relative positions; resize; connect; update connection; insertOnConnection with deterministic replacement IDs; reparent IDs to boundary/null; group IDs with supplied boundary; ungroup boundary IDs; paste clipboard fragment with supplied ID map/offset; metadata patch; order IDs foreground/background; applyLayout with expected revision and computed geometry.
- ClipboardFragment contains entities, internal connections and origin. `captureSelection(document, ids)` includes selected boundaries' descendants and omits external connections. Paste creates new IDs and detaches excluded parents, retaining absolute placement and internal membership.
- LayoutResult: retain existing `{diagram, revision}` shape; layout does not mutate its input. Command application guards expected revision, commits once and stamps valid routes.
- `EditorProps`: canonical document, canUndo/canRedo, readOnly, saveState (loading/saving/saved/error/read-only), backupDirty, message, isArranging/isExporting; callbacks onCommand, onUndo/onRedo, onNew, onOpen, onImport, onSaveJson, onArrange, onExport, onPreviewChange. Preview changes invalidate pending layout but are not durable history commands. Editor may hold local gesture/typing drafts and internal clipboard, never a second persistent document/history store. Export callback includes svg/png, 1x/2x and transparent option.
- Document APIs frozen for DGM-010: `validateDocument(input): Result<Diagram>`, `parseDocument(text): Result<Diagram>`, `importSkillSpec(input): Result<Diagram>`, `applyCommand(document, command): Diagram`, `captureSelection(document, ids): ClipboardFragment`.
- Persistence APIs: `createStorage(): {load():Promise<Diagram|null>, save(document):Promise<void>, close():void}` with clear errors; `watchSessionLock(onWritableChange): ()=>void` using Chromium Web Locks; second tabs start read-only and load the latest durable snapshot when the lock is acquired. Lock key is per-origin active-document, not per imported document ID.
- Layout/scene/export APIs retain the spike names and shape where compatible; frozen paths `src/layout.ts`, `src/scene.ts`, `src/export.ts`, `src/assets.ts`. Renderer may add helpers without changing caller contracts. Editor lives in `src/editor/Editor.tsx`, styles beside it. App wiring belongs to DGM-040.

Freeze concrete discriminant/property names in the shared types and return them in the final report so implementers do not guess. No production user-facing contract departs from the approved JSON v1 requirements.
