# DGM-115: Grid and Snap Controls

Date: 2026-10-11. Status: APPROVED AFTER DGM-114.
Parent: [DGM-100](DGM-100.md#dgm-115---grid-and-snap-controls).

Contract: optional `Diagram.grid?: { visible: boolean; style: 'dots'|'lines'; spacing: number; snap: boolean; present: boolean; export: boolean }`. Validate all fields, spacing integer4..128, finite values only; omitted grid effective `{visible:true,style:'dots',spacing:8,snap:true,present:false,export:false}`. Preserve omission in old JSON. One shared helper resolves defaults and absolute zero-origin grid; MetadataPatch accepts settings, commands validate/restamp routes without geometry mutation. Appearance controls are Document properties toggles Show grid, Snap to grid, Show grid in Present, Include grid in exports; segmented Dots/Lines, bounded numeric spacing field. Independence of visible/snap/export/present is explicit, style off achieved by visibility toggle.

When snap on, click/drop insertion, entity drag and supported resize snap using same grid origin/spacing, convert complete parent chain absolute-to-local once. Snap off must remove hardcoded helper rounding as well as ReactFlow snapToGrid. Group/subtree relative spacing preserved on drag; resize minima/containment prevail if exact grid dimension impossible. Keyboard nudge: preserve existing8/shift baseline when snap off; snap-on plain arrow advances one grid spacing and Shift four spacings. Duplicate/paste retain existing offset/relative spacing; with snap on align fragment root origin once, never round each descendant. Auto-arrange retains own geometry, not forcibly quantized. Changing settings never moves nodes; one undo restores settings/routes exactly.

Present ignores editing snap but shows grid iff grid.present; default hidden. Export grid included iff grid.export or explicit105 override; render below entities with same absolute origin/spacing including negative crop, panzoom and scales. Opaque uses114background; transparent keeps dots/lines with alpha between them. Avoid dense million-element SVG: native vector pattern with safe local IDs; no new assets/scripts. Controls accessible/touch44 and Present/readonly guards enforced.

Cases: all show/snap combinations+styles; off-grid click/drop/moves retained with snapoff; snap-on nested/group drag and parent relative conversion; resize limit handling; spacing invalid/undo/JSON/reload; keyboard/paste policy; Present include/hide vs editor; SVG/PNG grid pixel alignment and transparent pattern; no schema migration/order/membership/ELK change. Tests red before production, immediate focused validation after edit, typecheck and owner log area115. Allowed same shared settings/document/scene/export/editor files after114, interactions/tests and helper if necessary. No catalog/deps/desktop/layout algorithm/spec edits. Done: tests+logs and independent real-pointer and pixel checks. Escalate conflicts, no silent exclusion.
