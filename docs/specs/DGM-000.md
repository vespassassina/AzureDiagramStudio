# DGM-000: Visible Browser Feasibility Spike

Date: 2026-10-09. Status: SPIKE COMPLETE; PO REVIEW PENDING. Tier: Orchestrator spike exception.
Baseline: [DGM-MVP](DGM-MVP.md). Technical direction: [RFD 001](../rfd/001-editor-foundation.md).

## Context and hypothesis

Prove that React Flow interactions, ELK layout and skill-derived shared SVG scene definitions can produce one coherent visual editor and self-contained exports. Keep all application code under `spike/`; this is not production promotion or foundation authorization.

## Interfaces

Use framework-independent parent-relative entities, component/boundary IDs, plain-text labels and connection styles. Pure geometry/scene functions are the source of both custom React Flow visuals and exports. Layout requests carry a revision and run in a browser worker; result application is explicit and undoable.

## Acceptance cases

- Given a fixture with two nested boundary levels and cross-boundary/group endpoints, when rendered and moved, then child transforms and attached connector paths remain correct.
- Given a manually edited fixture, when an ordinary edit occurs, then unrelated positions do not change; when Auto-arrange completes, then one undo restores exact prior geometry.
- Given edits during a layout request, when its stale result returns, then newer work is not overwritten.
- Given labels containing markup characters, when shown or exported, then they remain inert text and cannot add markup.
- Given the same scene, when SVG and 1x/2x PNG are exported, then full content is present, icons/text render, dimensions scale correctly and SVG contains no external resources or `foreignObject`.
- Given desktop and 390x844 viewports, when tools and properties are used, then the canvas is nonblank and controls do not overlap.

## Visible slice

Display an explicitly synthetic architecture fixture, compact tools/library sidebar, direct selection/movement, contextual label/style edits, component insertion/deletion, connector creation, undo/redo, direction selection and export. These serve the spike, not a claim of completed MVP coverage. Browser persistence, complete skill import, all 24 Azure services, edge insertion, comprehensive grouping commands and mobile productivity belong to later tasks.

## Validation and done

Write/confirm failing geometry and escaped-export tests before their implementations. Run focused tests after each slice; build/typecheck and browser checks after integration. Inspect desktop/mobile screenshots and actual SVG/PNG output. Record exact versions/license notices, approved font/icon provenance and a supported PNG pixel cap. Start a local server and provide its URL.

Publish a go/no-go report with evidence, remaining risks and proposed production follow-up. End at PO review. No commits, branches, backend, deployment or unapproved dependency expansion.
