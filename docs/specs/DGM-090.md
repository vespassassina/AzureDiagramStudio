## Theme Contract

Theme is UI-only `light`/`dark`, locally persisted outside Diagram JSON/history. Default follows the system preference when no explicit preference is stored. A familiar Sun/Moon icon button names the action and is keyboard-accessible. Theme remains available in read-only sessions. Storage denial cannot crash the editor or report a fake diagram autosave.

Use CSS variables/data-theme for surfaces, labels, borders, focus, disabled state, search, inspector, toolbars and menus. Preserve the accepted quiet visual language and mobile fit. Canvas/chrome may be dark while diagram tiles retain their designed document colors; exports remain controlled by export options, not UI theme. Theme changes must not mutate document revisions, replace data, change ownership or invalidate file backups.

Test reload persistence, initial system choice, invalid storage fallback, both read-only and writable toggle, no document/history changes, contrast/overflow and desktop/mobile screenshots. Existing source/editor field-memo regressions and original performance gates remain.
