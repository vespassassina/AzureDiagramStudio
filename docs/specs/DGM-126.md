## Interfaces And Behavior

- Add an accessible **About** button adjacent to Help in the drawing tool rail.
  It is available in editable and read-only sessions, not within Present.
- The dialog shows the original bundled application logo, exact product name,
  version derived from existing package metadata, a brief local-first purpose,
  public repository and documentation references, independent/not-Microsoft
  identity, notices/license qualification and the JSON-backup reminder.
- Do not claim a signing status, actual executable architecture, new release,
  blanket artwork license, telemetry policy or supported-platform certification
  that the renderer cannot establish. No new runtime network requests.
- Opening/closing is informational, not a document command. Preserve document,
  selection, camera, history, panel intent and unfinished title/label/Markdown
  drafts. Apply the established guide guards to active gestures/composition,
  modal overlap and pending async operations rather than interrupting them.
- Use a labelled modal dialog, visible close control, Escape dismissal,
  focus containment, background shortcut/pointer protection and focus return to
  the invoking About button. Support keyboard activation, light/dark themes,
  narrow 390px and short 720x450 layouts with scrollable reachable controls.
- Retain the ten ordered Help steps and target/reveal behavior. Update their
  text for eleven starters, Markdown Edit/Preview, temporary presentation ink
  and where About lives. Do not execute guide actions or alter guide restoration.
- Reuse existing CSS tokens/overlay conventions. No shared modal framework or
  broad editor refactor is required.
