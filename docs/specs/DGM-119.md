## Frozen Behavior

1. Connection handles: larger visible connector dots and a generous transparent
   hit region (approximately 28-32 CSS px at ordinary zoom), preserving the four
   attachment sides and source/target semantics. Increase real pointer hit area,
   not only appearance. Do not cover labels or make opposite handles ambiguous.
   Read-only/Present still prevent connections.
2. Escape cancels the active canvas gesture, not merely its preview: node and
   multi-node move, resize, new link/reconnection, and library drop if active.
   Restore original positions/size/routes and document/history; a later mouseup
   or pointerup must not commit that canceled gesture. Keep cancellation latched
   until its physical gesture ends; a fresh gesture must work normally. Respect
   composition/inline/modal focus guards. Do not change intentional draft rules.
3. Tooltips: preserve accessible icon names and discoverability with pointer
   hover and keyboard focus, but do not pin a tooltip because a mouse-clicked
   button retains focus. Close on pointer action, mouse leave/blur, Escape,
   scroll/resize, window blur and owner unmount/disable or relevant mode change.
   Avoid duplicate native/custom tips and stale portal placement; a new genuine
   hover/keyboard focus can show the current tooltip again. Never make tooltips
   consume clicks or leave another control's tooltip stranded.
4. Right click on canvas, component/boundary or connection opens an accessible
   clamped context menu with target-appropriate existing actions: Add component,
   Add boundary/text/rectangle at the clicked canvas point, connect from the
   targeted component/boundary, delete/copy/duplicate where eligible, Properties,
   and Undo/Redo/paste where applicable. A link exposes its existing properties
   and delete behavior; canvas Properties means document properties. "New item"
   adds to the current diagram, not a destructive New diagram replacement.

The context target must be explicit; right-clicking an unselected object must
not mutate the previously selected one. Reuse existing commands and exact Undo,
including incident-connection cleanup. Disabled actions remain non-mutating in
read-only/loading, and no editing context menu opens in Present or over another
modal/Help. Preserve the right-button drag pan gesture where supported: a drag
must not accidentally execute a context action. Context actions must not run
against a changed document or stale target after opening.

Menu keyboard behavior: menu/menuitem roles, initial eligible item focus,
Arrow/Home/End navigation, Enter/Space activation, Escape/outside click/Tab
dismissal with sensible focus restoration. ContextMenu key or Shift+F10 opens
at the focused/selected object or canvas when editing owns focus. Clamp and
scroll within small/short viewports; icons and labels follow the existing UI.
