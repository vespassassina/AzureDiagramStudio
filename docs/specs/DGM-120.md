## Frozen Behavior

- Preserve existing pan/zoom/navigation on entering Present. Add icon controls
  for Navigate and Draw, five color swatches (red, blue, green, yellow, black),
  local markup Undo/Redo and Clear. Initial drawing color is red, with a thick
  approximately 6 CSS px round stroke, independent of zoom. Swatches show their
  actual colors and accessible selected names; controls have tooltips.
- In Draw mode, primary click+drag produces a freehand line. Shift+drag produces
  an unfilled rectangle, Alt+drag an unfilled circle/ellipse, and Ctrl+drag a
  straight arrow (Command also accepted for Mac-style keyboards). Modifier
  precedence is Ctrl/Command, then Alt, then Shift. Capture the shape at pointer
  start so mid-gesture modifier changes do not unexpectedly change its kind.
  Reverse-direction drags work; zero-area clicks do not commit empty objects.
- Escape during an active markup stroke cancels only that stroke and keeps
  Present open; later pointerup cannot commit it. Pointer cancel/lost capture
  also cancels safely. Escape while idle retains the existing Exit behavior.
  Undo/Redo/Clear affect only committed markup, never the diagram's history.
  Ctrl/Command+Z and redo variants may operate local markup while Draw owns focus;
  do not leak editor mutations into Present.
- Ink is session-only overlay state. It follows pan/zoom in diagram coordinates,
  stays above the artwork and below reachable presentation controls, and is not
  saved/exported, autosaved, placed in document history or present after exit/
  re-entry. Existing read-only diagrams can be marked up without editing them.
  Pan/Navigate makes the ink overlay non-intercepting; Draw blocks underlying
  node/connection editing and view panning during a stroke.
- Keep controls usable in fullscreen and on desktop/narrow/short viewports,
  including existing pointer/Exit/zoom controls. Account for toolbar bounds in
  fitting where needed. Use existing theme tokens, stable dimensions and familiar
  icon buttons/swatches. Do not change OS settings or native window minimums.

The quick menu is editing-only; no destructive diagram context action is exposed
by the markup overlay. No new permanent annotation schema, file format, eraser
engine, collaboration, persistence, packaging, Git/PR or publication scope.
