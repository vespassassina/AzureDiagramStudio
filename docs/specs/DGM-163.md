# DGM-163: Workbook Editing And Page Styles UI

Authority: PO request and page-removal choice, 2026-11-06.

## Context And Contract

Diagram creation must add to the current workbook rather than discard it.
This is a source UI refinement, not a new packaging/release request.
Editor-local starter insertion and removal use existing workbook-root
history, bounds and persistence; public MCP/CLI schemas do not expand.

## Acceptance Cases

- Given existing pages, choosing **Add diagram** appends the chosen blank or
  starter, selects it and preserves existing content. Adding to a standalone
  diagram explicitly promotes it while retaining the original page.
- The initial starter offer still initializes the first diagram; explicit
  **New workbook** retains its separate replacement safeguards.
- **Load** continues to replace the entire current workspace with the saved
  root, including every workbook page, subject to existing unsaved-work
  guards. It is not an additive page operation (PO clarification, 2026-11-06).
- The page strip places + directly after the last tab and has no ellipsis
  menu. Per-tab X removes pages with Undo, confirms non-empty removals and
  cannot remove the last page. Cancel preserves work; active removal selects
  the next available neighbor. Keyboard navigation/reorder and Present-only
  navigation remain available.
- Inline names commit on blur or Enter; Escape cancels, IME is respected and
  outside clicks keep their intended focus. Canvas-title double-click opens
  inline editing. Selecting the workbook breadcrumb then clicking again
  edits the workbook title without editing the active page.
- Select uses a white outlined arrow cursor; Pan and other tool cursors keep
  their intended behavior.
- Each page style has an accessible tab and retained drafts. Identity/meaning
  fields and Box/Connector appearance fields have clear labels and columns,
  with responsive theme-aware layout. All nine paint controls, inheritance,
  range validation, explicit used-state reassignment and atomic Apply/Cancel
  behavior remain. Removing invalid drafts cannot block the remaining styles.

## Out Of Scope And Risks

No persisted-format changes, dependencies, security policy changes, public
automation deletion tools, global instruction edits or new release assets.
Primary risks are accidental workbook replacement, stale draft commits,
history/page selection changes, inaccessible canvas hit areas and style
validation state leaking across tabs.

Definition of done: completed implementation, consolidated covering tests
and build, independent real-interaction verification, affected repair
recheck, and factual documentation. See [evidence](../verification/DGM-163.md).

## PO File Menu Follow-up

The PO subsequently requested this exact menu order and grouping:

1. New Workbook
2. Load Workbook
3. Save Workbook
4. Save Workbook As
5. Separator, then Add New Page
6. Add Diagram
7. Separator, then the retained Recent diagrams and Import skill JSON group

The PO explicitly chose to retain Recent/Import below the requested groups.
Add New Page creates a blank page directly; the trailing page-strip plus
shares that action. Add Diagram opens the starter chooser, subsequently
replaced by the approved [DGM-164 catalog](DGM-164.md). Preserve whole-root
Load/Save, replacement guards, page limits and keyboard menu navigation;
separators are not focus targets. This follow-up has separate validation
receipts and does not retroactively change the original batch's evidence.
