## Frozen Contract

Present is an explicit icon/text command in the editor. Complete valid pending edit before entering; validation failure remains visible and prevents entry. Capture camera, panels/pins, tool, selection and keyboard focus; hide editing chrome, grid, handles/resizers, selection outlines and attribution-independent editor overlays. Keep diagram title/status/legend semantic content visible. Enter with selected-content framing if entities selected, otherwise all content. Reuse shared entity/connection markup, not a second divergent diagram renderer. Presentation data remains session-only.

Guard ALL document mutations: toolbar/actions, global keyboard shortcuts, pane insert, node drag/resize, edge connect/reconnect, input/drop/import and pending async imports. Separate presentation guard from storage read-only; exiting must not override changed tab-lock ownership. Viewport pan/zoom/fit remain usable. No pointer/selection/camera changes trigger document/history/autosave/export content.

Provide temporary pointer via a named toggle and pointer-follow overlay, with keyboard operability and hidden state on exit. Optional fullscreen command uses browser API with denial fallback; in-window Present is default. Fullscreen Escape (fullscreenchange event) exits safely; Escape/Exit restore exact pre-Present camera/panel/pin/selection/tool/focus. Cross-document replacement invalidates the snapshot safely. Do not add global Electron permissions or new bridge.
