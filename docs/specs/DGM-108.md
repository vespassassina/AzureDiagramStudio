# DGM-108: Direct Editing and Keyboard Actions

Date: 2026-10-11. Status: APPROVED AFTER ALL SHARED EDITOR TASKS.
Parent: [DGM-100](DGM-100.md#dgm-108---direct-editing-and-keyboard-actions).

Contract: doubleclick/F2 selected node or edge label opens compact accessible inline input at artwork/label position, reusing existing draft/command limits. Singleline Enter commits once, Escape cancels; multiline text uses textarea, Ctrl/Meta+Enter commits and plainEnter newline. IMEcomposition not prematurely commit. Blur commits valid draft once; invalid stays editable with error. Inline draft doesn't move node/resize unexpectedly or trigger canvas/global delete/connect tool. One history transaction; crossdocument/readOnly/Present lifecycle invalidates/cancels as established. Background/grid/ordering paint/artwork unaffected.

Searchable command menu Ctrl/Meta+K (prevent browser search only while app owns keyboardfocus; never capture text-input shortcut unless intentional menu action) and icon command opens compact accessible dialog. Approved actions mirror existing toolbar APIs: tools, Present, Fit diagram/selection, undo/redo, duplicate/delete, group/ungroup, copy image/export, background/grid Document properties focus. Disabled actions honored and don't bypass presentation/storage guards. Menu state outside JSON. Arrow/Enter/Escape focus navigation, return origin focus; avoid OS collisions/new custom shortcuts. Entry label/edit command exposes F2 in menu/tooltips; no in-app explanatory paragraphs.

Cases RED doubleclick/F2 inline node+edge+notes, correctEnter/Escape/blur/IME/no shortcut bubbling, invalid limits, exactundo, readonly/Present/stale cancellation. Menu filtering same actions as actual callbacks, disabledstate, keyboard selection/cancel/focus, repeated invocation no duplicate history; tools/selection retained. Touchable44, small200%-viewport. Retain108logs. Allowed editor modules/tests/styles/interactions only; no shared domain/contracts/scene/layout unless proven integration blocker escalated. No dependency/desktop/security/spec edits. Done focused UI tests/typecheck + independent production browser flows. Excludes richtext/typepanel/configurable shortcuts and global app keylogger; human20s rename remainsmanual.
