## Frozen Contract

Use existing optional `Entity.order` and legacy layer fields without a version change. Legacy effective rank is background -1, boundaries 0, other foreground 4; ties retain document array order. Order is relative among siblings; a boundary subtree is one stacking unit. Paint traversal is ordered roots, each parent before its recursively ordered children. Moving a boundary never reverses its descendants. A selection containing parent and child operates on selection roots once. Selections spanning parent scopes are reordered independently per scope.

Four actions move the selection past one unselected sibling, or to its scope's extreme, retaining selected/unselected internal order. No-op at an extreme preserves the document, revision and history. Numeric ranks are assigned only in changed sibling scopes. Legacy background/foreground commands move selected roots to the corresponding sibling extreme even after numeric order exists. Imported finite numeric values retain sortable relative meaning; no new integer/range restriction or schema migration. Older clients are not promised lossless resave of new ordering metadata.

Expose one canonical painter order shared by commands, scene and canvas. React Flow's parent/select/edge elevation must not override it: use manual z-index mode and explicit node ranks, with visual selection affordances not raised fills. Render background objects, parent-first containers, connections, then foreground component/text objects. Within each band, traversal follows ordered sibling subtrees; a group command preserves descendant relative order within every band. Semantic bands take precedence over making a complete group indivisible across connections. This preserves readable legacy defaults (tiles above lines, lines above containers). Foreground/background legacy moves change appropriate object bands; four numeric actions reorder applicable sibling units without implicitly changing kind/layer semantics. A boundary stays under its own contents; nested background objects inside boundaries render after their parent and before foreground content. Define the stratum centrally, retaining `sceneLayers` compatibility. Parent-before-child visibility takes precedence over imported child ranks.

Decision clarification: asked the PO about the conflict between indivisible group stacking and legacy tiles-above-lines; PO was unavailable and explicitly delegated a good autonomous decision. Adopt the recommended readable architecture defaults. No new dependencies, document version or feature scope is introduced.

Stacking changes never change coordinates, boundary dimensions, connection points or label positions. On a non-no-op ordering revision, retain valid routes by restamping them to the resulting revision; stale routes remain stale. Preserve immutable command atomicity and ordinary exact undo.

## Given/When/Then Cases

- Given F1 `[front component, background rectangle, boundary]`, send already-bottom rectangle to bottom: all paint order, document and routes unchanged.
- Given contiguous/noncontiguous selection, all four actions retain selected/unselected relative order and move exactly one neighbor or to the scope extreme.
- Given nested overlapping boundaries, selection/deselection and canvas/SVG export show the accepted parent/child order. Boundary movement retains its subtree.
- Given numeric order followed by a legacy layer command, the command remains effective; JSON parse/serialize and paste retain sensible ordering.
- Given a stacking edit on arranged content, geometry/routes stay identical and valid; one history undo restores exact prior document.
- All four icon controls have distinct Lucide icons, names and tooltips; read-only behavior remains enforced.
