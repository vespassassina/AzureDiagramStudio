## Interfaces And Behavior

- Select one connector to expose labelled, keyboard-focusable segment handles.
  Drag a horizontal segment vertically or a vertical segment horizontally.
  Keep the route orthogonal, attached at the original endpoints, and preserve
  source/target sides, connection identity, arrow, line style and text.
  Endpoint reconnection remains a separate existing interaction.
- Offer handles for useful nonzero internal straight runs. A straight
  endpoint-to-endpoint route must also be adjustable: introduce the minimum
  orthogonal dogleg needed to offset its middle while keeping endpoints
  attached. Do not expose a handle that silently does nothing.
  Endpoint stubs/corners are not bend-point handles; maintain outward endpoint
  approaches and clamp unsafe collapsing/inverting geometry if necessary.
- Show a live preview, committing exactly one document/history edit when the
  pointer gesture finishes. No-op drags create no history/revision change.
  Escape, pointer cancellation/lost capture, stale document/revision, ownership
  loss and entering a guarded mode cancel without committing.
  Preserve selection, camera, entity positions and unrelated connectors.
- Honor Snap to grid on the moved axis in diagram coordinates; with snap off,
  do not quantize. Zoom/pan must not change the intended diagram displacement.
- Keyboard alternative uses the same focused handle and route algorithm:
  perpendicular arrows adjust the segment, with a larger Shift step;
  Escape cancels a preview and Enter/blur finishes one keyboard edit.
  Ignore unsupported parallel arrows; do not steal typing/IME/global shortcuts.
- Persist accepted geometry with existing points/labelPosition/routeRevision
  fields and schemaVersion1. No new persisted field, migration, MCP tool or
  public transport command. A narrowly typed internal document command for
  route adjustment/reset is permitted; keep external command allowlists intact.
  Validate IDs, finite bounded points, indices and revision atomically.
- Save JSON/open and autosave/reload, shared scene/Present/SVG/PNG and existing
  Markdown/ZIP output paths must use the accepted shape. UI handles never
  appear in exports or Present. Position the connection label on its route;
  update bounds so displaced segments and labels are not clipped.
- Keep valid adjusted geometry through non-geometric edits such as label,
  line/arrow, background and stacking changes. Moving/resizing objects,
  changing endpoint/attachment sides, topology/hierarchy edits or Auto-arrange
  may reset adjusted routes using the existing invalidation policy. No promise
  to preserve manual routes across geometry changes.
- Add one "Reset to automatic routing" action in Connection properties.
  It clears this connection's saved route using the existing automatic
  rendering policy, is undoable, and leaves other connections intact.
  Existing Auto-arrange remains the explicit whole-diagram obstacle-aware layout.
  Manual dragging does not run the obstacle router: crossing content is under
  the user's control, not a new automatic collision-avoidance guarantee.
- Preserve read-only/loading/Present/modal/inline-edit and MCP busy guards,
  existing reconnection, label double-click, selection/panning, drafts, history,
  focus, narrow/short layouts and both themes. Handle targets remain usable at
  practical zoom; cursor communicates the allowed perpendicular movement.

## Given / When / Then Acceptance

1. Given horizontal/vertical orthogonal routes and a straight connection,
   dragging an offered segment produces the expected perpendicular displacement,
   orthogonal finite points and original anchored endpoints; other document
   content is unchanged. Cover degenerate/short runs, reverse directions,
   explicit endpoint sides, negative coordinates, nested boundaries, zoom/pan
   and snap on/off. Reject invalid/stale geometry atomically.
2. Given a real pointer interaction, selection shows useful handles; movement
   previews without persistent history writes, release commits once, no-op
   commits zero, Undo restores the exact original and Redo the adjusted shape.
   Escape/cancel/lost capture/stale revision/read-only transition restore
   committed state and suppress a late release.
3. Given a focused handle, actual keyboard adjustment, Shift step,
   Enter/blur commit and Escape cancellation work. Controls have accessible
   names, visible focus, adequate hit targets and light/dark contrast.
4. Given saved segment edits, actual JSON round-trip and autosave/reload recover
   geometry. Scene, Present, SVG and actual PNG1x/2x exports reflect it without
   handles or clipping. Shared Markdown/ZIP output remains consistent; check
   the shared output path rather than inventing a new export implementation.
5. Given appearance/label/metadata/stacking changes, adjusted points remain.
   Given the approved geometry/topology/attachment/Auto-arrange reset triggers,
   routes reset consistently. Reset to automatic is scoped to the selected
   connection, undoable and safe when already automatic.
6. Given read-only/loading/Present/inline editing or an active modal, no
   segment edit bypasses guards. Existing endpoint reconnection, label edit,
   selection and canvas pan remain functional. Verify real interactions at
   desktop, narrow390px and short viewports, light and dark themes; do not
   substitute control-presence assertions for interaction evidence.
