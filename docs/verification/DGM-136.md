## Frozen Shared Helper API For DGM-135

Import from `app/src/export-package.ts` (renderer/browser-compatible, no Node
imports):

```typescript
export const MAX_EXPORT_MEMBER_BYTES = 32 * 1024 * 1024
export const MAX_EXPORT_ARCHIVE_BYTES = 64 * 1024 * 1024
export function exportFilenameStem(title: string): string
export function createExportZip(
  image: Blob, imageFilename: string, description?: string
): Promise<Blob>
export function createEmbeddedMarkdown(
  png: Blob, description?: string
): Promise<Blob>
```

- Stem preserves the normal ASCII/hyphen/underscore sanitization and 80-character
  cap, fallback `architecture`; reserved Windows names receive `_`.
- ZIP accepts exactly one nonempty SVG/PNG/native JSON Blob, with matching
  `image/svg+xml`, `image/png`, or `application/json` MIME (charset permitted),
  and a safe filename ending `.svg`, `.png`, or `.json`. Unsafe/path-like,
  reserved, unsupported or overlong UTF-8 names throw.
- Supply `${stem}.${format}`; members are exactly that filename and `${stem}.md`.
  The returned Blob is `application/zip`; caller names the outer file
  `${stem}.zip`. Stored ZIP32 metadata is deterministic (1980-01-01, UTF-8 names,
  no extras/comments). CRC32 and central/local length fields are included.
- Description defaults to `''`. It is UTF-8 encoded unchanged, no newline
  normalization or invented content. Members are limited to 32 MiB; the whole
  archive including headers is limited to 64 MiB before output allocation.
- Embedded formatter accepts nonempty `image/png` with PNG signature and returns
  `text/markdown;charset=utf-8`, bounded to 32 MiB. Bytes are the exact description
  followed by `\n\n![Diagram](data:image/png;base64,BASE64)\n`. Caller names it
  `${stem}.md`. Some viewers block data images; document ZIP as the alternative.
- Helpers throw explicit errors before returning partial output. Caller catches
  and reports failures. Helpers do not access documents, drafts, paths, network,
  download UI or session/history. `createExportZip` is a packaging helper, not a
  PNG decoder; image rendering remains the existing export layer's job.
- MCP must capture one committed document/options set, render SVG or PNG through
  existing exporters (Markdown always uses PNG), then call the same helper.
  Native JSON uses its canonical captured bytes in a JSON Blob. Reject
  `format: 'markdown', includeMarkdown: true` before rendering. Return base64
  from the returned Blob using the DGM-135 transport contract; do not reimplement
  archive or Markdown formatting in main/preload.
