## Scope And Limits

- ARM64 was exercised on the ARM64 host; x64 was exercised under Windows
  ARM64 emulation, not on native x64 hardware.
- Both executables are unsigned.
- Native Visio open/edit/glue interoperability and real native OS chooser
  interaction remain unverified.
- JSON is authoritative; VSDX embedded images are not vendor master stencils.
- Supported headless CLI/stdio uses the source launcher, not direct portable
  bootstrapper stdio.
- Architecture starters are original synthetic conceptual reference material,
  not deployed or vendor-certified systems. Cross-cloud mappings require
  workload-specific decisions; the Spanner-origin adaptation does not preserve
  Spanner's global relational write semantics.
- No dependencies, packaging policy, security, CI, existing tags/releases or
  installed applications were changed by this release.
