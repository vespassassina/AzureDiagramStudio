# DGM-168: Legend, Fabric Apps And Component Search

Completed: 2026-11-19. Authority: PO request to allow legend hiding, add Fabric
apps and improve fuzzy/partial search. The PO selected expanding the Fabric
component library, not architecture templates.

## Delivered Source

- View > Show legend replaces the duplicate Properties checkbox as the
  canonical control for existing per-page legend visibility. It preserves
  Undo/Redo, saved content, Present/export behavior and edit guards.
- The browsable Microsoft Fabric menu expands from 12 to 31 components using
  existing bundled assets, including Apps. Its 46 canonical searchable
  identities are retained; no dependency, asset download or schema change.
- Shared sidebar/picker/Favorites search normalizes case, punctuation and
  whitespace, prioritizes exact names/aliases, then phrase/substrings,
  all-token partial matches and conservative one-edit whole-word typos.
  Fuzzy query tokens require at least five characters; short tokens are not
  fuzzy-expanded. Stable ranking, memoization and lifecycle guards remain.
- Full category/group phrases remain discoverable, but navigation-group
  words do not manufacture unrelated multiword component matches.
