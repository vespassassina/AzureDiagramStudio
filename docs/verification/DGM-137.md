### Correction And Exact Geometry Contract

`layout-stacked.ts` now lays out measured boundaries bottom-up using real flat
ELK graphs at each hierarchy. A boundary is an opaque measured unit in its
parent graph, with fixed perimeter ports backed by its already-routed internal
paths. Real ELK external terminals allow outgoing paths to be routed and clipped
to that boundary before its parent routes the next segment.

- **RIGHT+stacked root:** all root boundaries and ungrouped components share
  exactly the same left x; disjoint y intervals increase in document order.
- **DOWN+stacked root:** all such units share the same top y; disjoint x
  intervals increase in document order.
- **Every boundary, RIGHT:** all immediate component/boundary units form one
  top-aligned row in document order, recursively through nested contents.
- **Every boundary, DOWN:** those units form one left-aligned column.
  The root alone reverses the requested axis; nested contents do not alternate
  axes or use dependency levels as groups.
- Each real unit has an ordered ELK partition and common transverse input
  coordinate; interactive placement/crossing minimization retains that
  constraint. Locally bounded track reserves accommodate routing nodes.
- Root spacing is measured from ELK's routed result. Invisible ELK spacing
  units are adjusted and the graph is **rerouted** to equalize the measured
  outer gaps. Inner flow spacing retains ELK's 100px minimum plus routing/label
  requirements. Neither nodes nor edge endpoints are manually snapped after
  routing.
- The bundled engine can mutate its input. Every routing attempt receives a
  fresh structured clone, so a preceding result cannot silently replace the
  next attempt's coordinate constraints. The retained empty/disconnected/
  backward-boundary case caught this during repair.
- Route concatenation translates complete module geometry together, handles
  ELK edge-container origins, and joins identical fixed perimeter endpoints.
  Explicit sides, labels, hierarchy, component dimensions and absolute text/
  rectangle annotations are preserved. Ordinary labels remain ELK-positioned;
  a boundary-to-own-descendant label is placed on its retained routed segment,
  not beside a discarded external terminal.
- Standard modes and no-group fallback retain the original directed ELK body.
  Transient options, saved JSON, public/MCP contracts, history, cancellation,
