   `app/test-results/dgm149/independent/production-browser-results.json`.

   sequences contain only `read(entry-one)`; no acknowledgement/record call
   occurs. See `existing-original-reopen` in the same results file.
3. **Modal focus is not restored.** Both Escape and Close leave the active
   element as `BODY`, observed in `browser-only` and `list-narrow-longpaths`.

No speculative fix was attempted. Return these findings to the implementation
owner; rerun the independent acceptance pass after the three behaviors are
repaired. Do not start the next queued feature until DGM-149 acceptance closes.
