## Owner Renderer Repair — 2026-11-05

The retained independent failure was reproduced first against the actual Editor:
select Blue, enable the grid, then select Lines. The new source browser
regression observed the Dots circle at `rgb(0, 112, 192)` and the Lines path
at `rgb(196, 210, 206)` before the repair.

The root cause was the existing `.react-flow__background-pattern.lines` CSS
rule. It paints from `--grid-dot`, while the canvas set that variable only to
the Automatic contrast-derived color. React Flow's Dots path retained its
explicit fill, but its Lines path was overridden by the stale variable.
`EditorSurface.tsx` now assigns `--grid-dot` from `grid.color` whenever an
explicit color exists; otherwise it retains the exact prior Automatic
contrast-aware value. No grid flags, palette values, defaults, document
contract, or export behavior changed.

Owner RED/GREEN evidence is retained under `app/test-results/dgm156/owner/`:
`repair-receipt.json` records the final source and evidence paths, sizes,
SHA-256 identities, commands, and exits.
