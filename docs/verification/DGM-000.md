## Findings and Fixes

- Derived React Flow nodes discarded measurements and broke dragging. Canonical explicit dimensions fixed the browser regression.
- Bundled ELK inside a wrapper worker failed with `_Worker is not a constructor`. Official `elk-api.js` workerFactory and `elk-worker.min.js` work without a new dependency.
- Screenshot inspection found inner-group routes using root coordinates. A red endpoint test confirmed detachment; translation using each edge's container origin fixed it. Rendered endpoints are now checked automatically.
- Undo tests sampled selection z-index as geometry. Transform/size-only sampling matches the approved separation of document and session state; geometry assertions remain exact.
- Integrated-browser download events were unavailable. Local headless Edge captured and checked real files.
