## Verified Tool Contract

- Discovery/read: `get_document`, `search_catalog`, `list_templates`,
  `get_app_info`.
- Mutations: `create_diagram`, `edit_diagram`, `arrange_diagram`, `undo`, `redo`.
- Stateless authenticated Streamable HTTP JSON; address
  `http://127.0.0.1:<actual-port>/mcp`. Preferred port is 37431; bearer token is
  generated per app launch and copied separately, never embedded in the address.
- Reads and successful writes return JSON text with `{document, stateToken}`.
  Every mutation requires the current opaque `stateToken`.
- `create_diagram`: `{stateToken, template?}`; missing template means blank.
  `edit_diagram`: `{stateToken, commands}` with 1–100 canonical commands, bounded
  additionally by the 64 KiB HTTP request limit; one atomic history step.
  `arrange_diagram`: `{stateToken, direction: "RIGHT" | "DOWN"}`.
  Undo/Redo: `{stateToken}`.
- `applyLayout` is not accepted from clients; arrange uses the existing worker.
  Complete argument schemas are published by `tools/list` from
  `app\electron\mcp-schema.mjs`.
- Correlated broker timeout 4 seconds; HTTP timeout 5 seconds; 8 simultaneous
  HTTP requests, 32 connections; IPC snapshot/result bound 8 MiB and native
  document bound 5 MiB. Failures are tool errors or JSON-RPC/HTTP errors, not
  silent session refusals.
