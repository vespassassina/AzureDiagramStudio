## Contract and implementation

- `electron/workspace.mjs` owns OS Documents resolution, app-profile preferences,
  bounded export validation, stable workspace mapping and atomic file writes.
  `main.mjs` supplies `app.getPath('documents')` and profile `userData`.
- Fixed sandbox preload API `window.desktopWorkspace` exposes only
  `read()`, `choose()`, `reset()` and
  `save({documentId, filename, mimeType, bytes: Uint8Array})`.
  No operation accepts a renderer path. Choose/Save paths come only from native
  dialogs in main. Registered live-main-frame validation applies at dispatch
  and after native/async completion. Existing security/CSP/permission/download
  policies are unchanged.
- Profile file `workspace-settings.json`: `{version:1,root:null|string}`;
  null means the current OS Documents/AzureDiagramStudio default. Read is bounded
  to 16 KiB. Corruption/unreadability is explicit, never silently replaced.
  Choose/Reset alone change the preference. Sibling exclusive writes, flush
  and rename preserve the previous setting on persistence failure.
- Frozen folder mapping: resolved root / `workspace-` + **full lowercase SHA256
  of the canonical document ID encoded as UTF-8**. Identity is not title-based;
  renaming stays in one folder, separate newly generated document IDs cannot
  accidentally share a title-derived folder. Root changes affect later
  destinations; old directories remain. Existing documents/recovery are not
  rewritten or migrated. Imported copies retaining the same canonical ID
  intentionally refer to the same workspace identity.
- Root/folders materialize only on an explicit actual save/export request.
  Missing selected roots fail; the app never silently falls back or recreates
  an explicitly selected root. The default may create only the app-owned leaf
  under existing usable OS Documents. Redirected child folders are rejected.
- Save JSON, SVG, PNG, companion ZIP, embedded Markdown and PNG clipboard
  fallback share the bounded desktop adapter. Main validates exact fields,
  1–128-character canonical IDs, safe filenames/MIME and 1–64 MiB bytes,
  invokes `showSaveDialog` with the workspace filename as `defaultPath`, then
  atomically saves only to the native-confirmed destination. Cancellation
  returns false, retains JSON backup-dirty state and reports cancellation.
  File-write failure cannot truncate an earlier destination.
- Renderer `app/workspace.ts`, `browser.ts`, `session.ts` integrate the adapter.
  Settings shows resolved absolute root, Choose/Reset and honest status/scope.
  Browser builds keep their existing downloads and explain desktop-only root
  configuration. MCP continues to use captured in-memory bytes; it never
  invokes the destination adapter.
- Desktop source staging includes the ninth shell file `workspace.mjs`.
  Existing DGM-135/137 source harness copy lists and shell allowlist tests
  include that module; no package was staged/built.
